Pig-6 API

Interact with the Pig-6 economy from your own applications using a personal API key — check the market, read the leaderboard, and manage your own balance, codes and transfers.

Authentication

Protected endpoints require an API key, sent in the HTTP Authorization header using the Bearer scheme.

The API identifies the Pig-6 user automatically from the API key — you never need to send a Telegram user ID yourself.

Header 
Authorization: Bearer YOUR_API_KEY

Public endpoints

GET /api/market No auth required

Returns information about the current anonymous-code market: how many codes are available, and the current buy and sell price for one code.

Response 
{
    "available": 100,
    "buy_price": 150,
    "sell_price": 120
}
GET /api/top No auth required

Returns the Pig-6 leaderboard, sorted by P6T balance from highest to lowest.

Query parameters
limit optional — how many users to return
Request 
GET /api/top?limit=10
Response 
[
    {
        "rank": 1,
        "name": "Alice",
        "balance": 15000
    },
    {
        "rank": 2,
        "name": "Bob",
        "balance": 12000
    }
]

Authenticated endpoints

GET /api/balance Auth required

Returns the authenticated user's current P6T balance. The user is determined automatically from the API key.

Response 
{
    "user_id": 123456789,
    "balance": 1500
}
POST /api/buy Auth required

Purchases anonymous codes using P6T. Authenticates the user, checks availability and price, confirms the user has enough P6T, charges them, then delivers the codes.

Query parameters
count optional — number of codes to buy, defaults to 1
Request 
POST /api/buy?count=5
Response 
{
    "status": "ok",
    "user_id": 123456789,
    "count": 5,
    "price": 750,
    "balance": 750
}
Possible errors
  • Invalid API key
  • Not enough codes
  • Insufficient funds
POST /api/sell Auth required

Sells anonymous codes owned by the authenticated user. Confirms the user owns enough codes, calculates the current selling price, removes the codes, then credits P6T.

Query parameters
count optional — number of codes to sell, defaults to 1
Request 
POST /api/sell?count=3
Response 
{
    "status": "ok",
    "user_id": 123456789,
    "count": 3,
    "price": 360,
    "balance": 1860
}
Possible errors
  • Invalid API key
  • Not enough codes
  • Sale failed
POST /api/pay Auth required

Transfers P6T from the authenticated user to another Pig-6 user, found by username. Checks the sender's balance, transfers the amount, and returns the updated sender balance.

Query parameters
username recipient's Pig-6 username
amount amount of P6T to transfer
Request 
POST /api/pay?username=@alice&amount=100
Response 
{
    "status": "ok",
    "sender_id": 123456789,
    "receiver_id": 987654321,
    "username": "@alice",
    "amount": 100,
    "balance": 1400
}
Possible errors
  • Invalid API key
  • User not found
  • Insufficient funds
  • You cannot transfer funds to yourself
  • Transfer failed
POST /api/bonus Auth required

Claims the user's periodic P6T bonus. The user is identified automatically from the API key. The bonus can only be claimed again once the cooldown period has expired.

Response — success 
{
    "status": "ok",
    "user_id": 123456789,
    "amount": 427,
    "balance": 1927
}
Response — cooldown active 
{
    "error": "Bonus not available",
    "remaining": {
        "hours": 5,
        "minutes": 42
    }
}

API summary

Method Endpoint Auth Purpose
GET /api/market No View code market
GET /api/top No View leaderboard
GET /api/balance Yes View your balance
POST /api/buy Yes Buy anonymous codes
POST /api/sell Yes Sell anonymous codes
POST /api/pay Yes Transfer P6T
POST /api/bonus Yes Claim bonus

Important

All prices and balances are denominated in P6T, the internal currency of the Pig-6 ecosystem.

API keys are personal credentials. They must not be exposed publicly, committed to repositories, or embedded directly into frontend code.
