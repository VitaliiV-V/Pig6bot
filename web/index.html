What Pig-6 does

Five cooperating bots sharing one config, built to keep a channel's identity, content and admin list under control.

Identity

Channel protection

A rotating name + invisible UUID pair confirms that a post really came from the registered owner, a super user, or a protected channel. Impersonation attempts are deleted on sight, and the UUID rotates after every legitimate post so a captured signature can't be replayed.

Blacklist

EXCOMMUNICADO

A permanent mark that strips a protected channel or user of its protection and adds it to the blacklist. Once applied it's final — the entry is cut off from the network for good, managed by Alpha users from the admin panel.

Media

Media download

Pulls any photo, video, document or voice message posted in the main channel straight to the requesting user, no forwarding required — just reply to the post with the command.

Signing

Certificates

Registered users get an Ed25519 keypair and can sign any message inline. Each signed post carries a verification link so anyone can confirm it's authentic, with optional shadow-role visibility.

Moderation

Content filtering

Off, manual or full lockdown moderation modes, with leetspeak-aware word filtering, per-user and per-GIF bans, a whitelist system, and automatic lockdown if 10+ messages land within 5 seconds.

Emergency

Judgment Day protocol

A dedicated lockdown mode: the channel switches to maximum security and a separate bot deletes any message that doesn't carry the current secret code, which rotates after each use.

Control

Admin panel

An inline dashboard for Alpha users to toggle moderation and Judgment Day, and to browse and manage protected, super and signed users.

Assistant

Jarvis AI

A Gemini-powered assistant that responds when mentioned and runs the same protection pipeline on every message. A designated master user can issue natural-language admin commands to it.

Economy

P6T token economy

A lightweight SQLite-backed economy tracking balances, peer-to-peer transfers and a redeemable-code marketplace with price history.
